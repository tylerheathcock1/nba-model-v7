# v7 backtest (11/19/26)

**Data:** public box scores 2010-11 to 2023-24 (player minutes, box stats, +/-) and a public line archive of near-closing spreads. Months where the odds were attached to the wrong games were dropped.

**Method:** each week, fit ratings on prior games only, then predict that week's games.
- **Team:** recency-weighted ridge ratings from game margins. This is the v5/v6 approach.
- **Box:** Game Score per 48 for each player, multiplied by projected minutes.
- **RAPM:** player ratings from a ridge regression of game margins on minutes played, pulled toward the box-score rating. Team strength = sum of player rating × projected minutes (an EWMA of recent minutes, rescaled to 240).
- **Availability:** in the backtest, the players who actually played. This flatters the model; live, it uses the injury report.

**Settings** were chosen on 2011-19 accuracy only (HL 300 days, ridge 30, prior scale 0.35). 2021-24 was untouched until the final check.

## Results

| | Train 2011-19 RMSE | Holdout 2021-24 RMSE |
|---|---|---|
| Closing line | 12.09 | 13.20 |
| **Player model (RAPM)** | **12.14** | **13.41** |
| Team model (v5-style) | 12.43 | 13.91 |
| Box only | 12.73 | 13.98 |

- **Players beat teams:** the player model is about 0.5 pts more accurate than the team model on the holdout.
- **Neither beats the close:** both are less accurate than the closing line.

**Information beyond the close.** The weight the best blend puts on (model minus close):
- **Train:** +0.39.
- **Holdout:** +0.12 (t = 1.4). By season it was 0.35, then 0.15, then -0.09, so the closing line got sharper each year.
- **Betting against the close:** holdout ATS when |model - close| >= 3 is 47.0%, and at >= 4 it is 46.0%. There is no edge against the close.

## What this means

- **v7 is a better forecaster than v5/v6's team ratings,** but it does not beat closing lines.
- **The remaining question is timing.** Does it beat the morning line, meaning does the line move toward v7 between the morning and the close? The archive has no opening lines, so this can only be tested forward. The live slate logs the ESPN/DraftKings opening and current lines for exactly that reason.
- **Stake:** run v7 at 0u. Judge it on line movement and CLV.

Run these from the repo root:

```
python backtest/v7bt.py 300 30 0.35 work/pred.parquet
python backtest/v7eval.py work/pred.parquet
```

The scripts expect the public datasets cloned at `ext/` (kyleskom/NBA-Machine-Learning-Sports-Betting) and `ext2/` (NocturneBear/NBA-Data-2010-2024), and a `work/` folder.
